# Ativar o monitoramento diário

O agendamento usa a tarefa agendada do Claude Code (app desktop). Roda com a sua assinatura Pro, sem API extra. Limites: a tarefa só dispara com o app aberto; se o app estiver fechado no horário, roda ao abrir.

Prompt completo: `docs/monitor/prompt.md`. Fontes: `docs/monitor/fontes.md`. Registro: `docs/monitor/registro.json`.

## Como ver ou pausar

Na aba Code do app, em tarefas agendadas (ou peça aqui: "liste minhas tarefas agendadas"). Para pausar, desative a tarefa `ctrl-monitor-atualizacoes`.

## Ajustar horário

Padrão: todo dia às 09:00 (hora local). Peça para alterar o horário, se quiser outro.
